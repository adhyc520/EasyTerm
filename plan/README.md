## 关键入口（实现后）

| 能力 | 怎么用 |
|------|--------|
| 终端搜索 Aa / 正则 | 终端内 Cmd/Ctrl+F |
| 命令书签面板 | Cmd/Ctrl+Shift+P |
| 键盘复制模式 | 终端复制模式快捷键（见 shortcuts） |
| 会话录制 | 终端录制控制条 |
| Exposé | 桌面 Cmd/Ctrl+E；右键菜单「窗口概览」 |
| Snap 布局选择器 | Cmd/Ctrl+Shift+Z |
| 桌面小部件 | 桌面右键 → 添加小部件 |
| 任务栏自动隐藏 | 桌面设置开关 |
| 会话恢复 | 启动时若有 autosave 弹出恢复对话框 |
| 批量执行 / SSH Config / 分组 | 设置菜单相关入口 |
| 触控辅助栏 | 终端设置 → 触控辅助栏 |
